## 一、先给总判断

当前这版 `SKILL.md` 已经比初稿稳很多。

该有的主骨架基本都有了。
触发边界已经收过一轮。
事实题先研究、再给事实底稿、再进入毛式分析，这条工作流也已经立住。
阶段分层、群众路线、利用敌人之间矛盾、先定性质再定方法这些高辨识度模块，也都已经吸收了一大截。

但全量回看 research 之后，还是能看出三类问题。

第一类是 `SKILL.md` 还在同时承担三种角色。
它既想做执行手册。
又想做方法论摘要。
还想做半份人物总论。
结果就是有些该写死的动作还不够硬，有些该下沉的研究性内容又还留在主文件里。

第二类是张力写出来了，但还不够制度化。
现在已经写到早晚期断裂、人民内部矛盾和反右的反差、统一战线与高压治理并存、对外现实主义和对内路线斗争并存。
可这些更像知识点，还没完全变成 agent 的强制提醒。

第三类是表达禁忌还可以继续收紧。
现在已经禁了一部分 AI 味和现代企业黑话，也压住了纯模仿腔调。
但全量回看 `22-style-and-method.md`、`03-expression-dna.md`、`08-high-tension-nodes.md` 后能确认，真正容易跑偏的不是不会像毛，而是太像廉价毛腔调生成器。

所以这一轮最该做的，不是补更多史料到 `SKILL.md`。
而是做一次更彻底的分层。
把 `SKILL.md` 压成执行文件。
把 research 留在 `references/` 做证据和维护层。

## 二、修订总原则

这轮建议按四条总原则动。

第一条。
`SKILL.md` 只保留会直接改变 agent 行为的内容。
也就是触发、退出、边界、研究流程、输出骨架、风格硬约束、时期判断提醒、资料路由。

第二条。
凡是解释性强、举例多、跨时期综述性强、证据链密集的内容，尽量下沉到 `references/`。
`SKILL.md` 里只保留一句能驱动行为的压缩判断，再给路由。

第三条。
所有高风险张力都不要只当研究结论。
要改写成 agent 的提醒句和禁令句。
比如不要把 `1957` 的柔性框架当成稳定制度现实。
不要把 `1937—1945` 的统一战线逻辑机械套到 `1966—1976`。
不要把群众路线写成讨好群众或煽动群众。

第四条。
表达层不追求更像。
追求更稳。
重点是结构像、判断程序像、对象意识像、阶段感像。
不是词汇 cosplay。

## 三、哪些研究结论必须进 `SKILL.md`

这一部分只列应该写进主文件、并且会直接改变 agent 输出质量的内容。

### 1. 时期分层必须保留，而且要再压成硬提醒

现有 `SKILL.md` 已经有六段分期。
这方向对。
而且是这轮 research 最值得进主文件的成果之一。

原因很简单。
`15` 到 `21` 这一组分期研究已经足够证明，毛不能被写成一个从青年期到晚年始终平滑一致的稳定战略家。
青年期、统一战线期、战争期、建国初重建期、高社会主义期、文革晚年期，不只任务不同，反馈机制、组织边界和现实处理方式都不一样。

建议保留分期，但把写法再收成执行提醒。
重点不在展示分期知识，而在防止 agent 乱套方法。

建议在 `SKILL.md` 里明确加三句性质的硬提醒。
一是先判断用户问的是哪一段，再调用相应判断框架。
二是早期调查、统一战线、根据地经验，不能自动替晚年群众动员和路线斗争背书。
三是涉及 `1957—1976` 时，默认存在公开理论和实际处理之间的高张力，不能只顺着官方口号说。

这块对应来源主要是 `15`、`16`、`18`、`19`、`20`、`21`、`08`。

### 2. 事实底稿机制必须保留，并补一条时期与争议点要求

现有 `SKILL.md` 已经要求事实题先做 3 到 6 句事实底稿。
这条必须保留。

但全量回看 research 后，建议多补一条。
事实底稿不只要覆盖对象、时间、阶段、争议点。
还要尽量点出这个问题对应的时期位置，尤其是涉及毛本人、路线争议、政策评价时。

原因在于很多问题不是缺事实，而是缺放置位置。
比如问群众路线。
问统一战线。
问人民内部矛盾。
问反修。
不先说它对应哪段，后面就很容易把不同阶段揉在一起。

这个补强结论主要来自 `18`、`19`、`20`、`21`、`08`。

### 3. 主要矛盾 对象划分 阶段判断 动作建议 这条四段骨架必须保留

这条已经是当前 `SKILL.md` 的主心骨。
不用推翻。

研究全回看后，反而更证明它是对的。
无论是青年期的先小联合再大联合。
还是 `1927—1935` 的空间重排。
还是抗战时的统一战线与独立自主。
还是建国后的阶段重定。
还是 `1957—1976` 的多次定性升级。
真正最稳定的，不是某句口头禅，而是先定性质、再分对象、再判阶段、最后排动作。

建议只做一个收紧。
把四段骨架从建议式措辞改成默认输出结构。
并明确说明，除非用户要求纯历史说明，否则正式回答尽量按这四步走。

这块的强支撑来自 `01`、`05`、`06`、`18`、`22`。

### 4. 先定性质 再定方法 这条必须保留，但要升级风险警示

这条非常毛。
也是最危险的一条。

`review-b` 已经点过一次。
`22-style-and-method.md` 和 `08-high-tension-nodes.md` 又把它坐实了。
从 `1957` 到庐山，再到社教和文革前夜，这条方法一旦把本可讨论的问题升级定性，处理烈度会瞬间变掉。

所以它必须留在 `SKILL.md`。
因为这是高辨识度方法。
但表达方式要更像危险品说明。

建议保留在启发式或高危提醒里，并加一句更硬的提醒。
即这条只用于分析框架，不可把现实分歧、组织冲突、正常批评直接套成敌我斗争建议。

支撑来源是 `20`、`21`、`08`、`22`。

### 5. 群众路线的写法必须保留现在这版，不要再退回通用组织学

这轮 research 对这一点的结论很明确。
`review-b` 提过。
`15`、`18`、`22` 都再次印证。

群众路线如果写成用户洞察、社区运营、倾听基层声音，这就废了。
真正该留在 `SKILL.md` 里的，是现有这版更接近的写法。
不是跟着群众情绪走。
而是把分散经验提炼成路线，再组织群众执行。
同时保留滑向代群众发言和动员口号的风险提醒。

这一条建议不要动回去。
只建议加一句红线。
任何面向现实组织和公共议题的回答，都不能把群众路线写成鼓动群众冲击制度或绕过正常程序的操作手册。

### 6. 利用敌人之间的矛盾打开空间 这条必须保留

这条已经吸收进了当前 `SKILL.md`。
应该保留。

理由也更充足了。
从 `1926—1927` 统一战线线索。
到抗战中的联蒋抗日。
到 `1971—1972` 的中美接近。
这条不是偶发表现。
而是跨时期复现的高生成力模型。
符合 extraction framework 里的三重验证标准。

建议在 `SKILL.md` 里维持它作为独立启发式。
但补一条限定。
涉及现实问题时，优先把这条理解成阶段性排序与次序重排，不是价值认同转换。

### 7. 表达禁忌里必须加入 不要为了像而滥用敌我口号

这条现在还不够硬。

全量回看 `03`、`22`、`08` 后，最常见跑偏方式不是结构失真，而是 agent 为了模仿毛式气味，动不动就上纲到敌人、路线斗争、镇压、纸老虎、炮打司令部这类词。

所以建议在 `SKILL.md` 的禁止项里再补一条。
不要为了口吻而把普通分歧夸张成敌我矛盾。
不要滥用历史高压词汇当修辞装饰。

这一条会直接提升安全性和成熟度。

## 四、哪些研究结论不该进 `SKILL.md`，应留在 `references/`

下面这些内容很重要。
但不适合继续堆在主文件。
它们更适合做资料层、维护层、或回答时按需调用的参考层。

### 1. 各时期长篇事实综述

`15` 到 `21` 这一整组分期稿，价值很高。
但它们的价值主要是提供事实底稿、张力地图和时期路由。
不适合直接压进 `SKILL.md`。

原因很简单。
一旦主文件试图容纳这些长综述，就会重新膨胀回人物总论。
而不是执行手册。

处理建议是。
`SKILL.md` 只留分期提醒和路由。
把长综述继续留在 `references/research/`。
必要时甚至在 `INDEX.md` 里把这组文件单列成 分期主稿。

### 2. 具体来源链接、文献入口、硬证据包

像 `14-current-round-merged-gap-map.md`、`31-gap-map-and-next-round-capture-plan.md`、`07-primary-source-map.md`、`09-gap-fill-source-pack.md`、`13-current-round-verified-gap-pack.md` 这些，全部该留在 `references/`。

它们适合维护者、研究者和回答前补证。
不适合让 `SKILL.md` 承担。

主文件最多保留一句路由说明。
比如需要原始来源入口时读哪份。
需要总账地图时读哪份。

### 3. 表达 DNA 的细颗粒拆解

`03-expression-dna.md` 和 `22-style-and-method.md` 很值钱。
但其中大量内容，比如高频词群、句法骨架、比喻来源、古典转译、战争修辞与政治修辞同构，这些不该完整搬进 `SKILL.md`。

原因在于这类内容一旦写太多，agent 会更容易学表面腔调，而不是学输出程序。

建议做法是。
`SKILL.md` 里只保留几条硬风格要求和禁止项。
更多表达解释继续留在 `22` 这类维护稿里。

### 4. 大量历史案例举例

现在 `SKILL.md` 的模型和启发式下面都有案例。
这个量基本够了。
不建议再加更多。

因为对主文件来说，案例太多会稀释执行规则。
如果后续还想扩写案例，优先应该单独做 `casebook` 或继续留在 `references/casebook.md`。

### 5. 维护史和历史评审过程文本

`review-a.md`、`review-b.md`、`31-gap-map-and-next-round-capture-plan.md`、本稿这类修订计划，都应该明确留在维护层。
不要回塞到主文件。

它们是给维护者看的，不是给运行时 agent 看的。

## 五、哪些表达禁忌还要继续加强

这一部分是这轮最值得补刀的地方之一。

### 1. 禁止廉价毛腔调

建议在 `SKILL.md` 里把下面这层意思写得更明白。

不要靠高频政治词堆气势。
不要靠连续短促口号制造毛感。
不要把敌人、路线、炮打、纸老虎这类词当调味料乱撒。

因为全量回看后很明显。
毛式表达最值钱的是结构。
最不值钱也最容易出丑的是词汇 cosplay。

### 2. 禁止把历史灾难节点写得太顺

`08-high-tension-nodes.md` 已经反复证明。
`1957`、庐山、七千人大会后反扑、社教到文革、林彪事件，这几处如果写得太顺，就会把断裂和代价洗没。

建议在 `SKILL.md` 的边界部分再加一条。
涉及大跃进、反右、文革、镇反等高代价议题时，不得只用战略成败语言覆盖后果和争议。

### 3. 禁止把群众路线写成煽动术

这条前面提过一次。
这里单独列出来。

因为很多模型一旦落到现实问题，最危险的误用就是把群众路线、统一战线、斗争方法，写成现实动员和冲击既有制度的实操建议。

建议主文件里明确说。
可以分析其组织逻辑，不可把它变成现实煽动模板。

### 4. 禁止把统一战线写成无边界合作万能钥匙

`18`、`19`、`21` 都说明，统一战线不是取消斗争。
但同样不能被反过来写成一切都能联合、一切都可操作。

建议补一句。
统一战线是阶段性排序，不是永久阵营。
涉及现实问题时，要明确联合边界和代价，不能空喊谁都能争取。

### 5. 禁止用现代企业黑话替代毛式分析

这一条已经在主文件里有。
建议保留。
不用再加长。
但可以顺手再加两三个典型词，像方法论沉淀、能力抓手、价值闭环这类，也一并禁掉。

## 六、时期分层和张力提醒 还应如何加强

### 1. 把 1917—1927 的青年与建党前史提醒再前移一点

现在主文件里六段分期主要从 `1917` 开始。
没问题。
但还不够提醒 agent 一个关键点。

青年期和建党前后，不是成熟毛主义已经完成的时期。
是身体改造、结社、群众联合、研究习惯、组织扩张这些方法零件逐步装上的时期。

建议在分期段后面补一句解释。
涉及青年期和 `1921—1927` 时，优先看方法形成与组织起步，不要提前投射晚年路线语言。

这会避免把青年毛写成后期毛的缩小版。

### 2. 把 1945—1956 的联合政府设计与一党领导现实张力写得更显性

`19-state-building-1945-1956.md` 是这轮很值钱的一份稿。
它最强的贡献不是补事实。
而是把 `1945` 联合政府、新民主主义、政协建国、共同纲领、镇反、三大改造之间的张力钉住了。

建议在 `SKILL.md` 的关键张力部分，多加一句类似这样的提醒。
建国初既有联合政府和过渡期设计，也有高压治理和快速改造并行，不能只拿其中一面代表整个阶段。

### 3. 把 1957—1965 明确写成 理论柔性与实际升级并存期

当前主文件已经提到了 `1957—1965` 的张力。
但还可以更像执行提醒。

建议直接写成一句压缩判断。
这段时期公开理论常保留柔性处理语言，现实处理却多次升级定性，回答这一段时必须同时看两条线。

这个提醒能直接改善 agent 对百花、反右、人民内部矛盾、社教这些问题的回答质量。

### 4. 把 1966—1976 的对内高压与对外现实主义并存写成默认提醒

`21-cultural-revolution-1966-1976.md` 和 `08-high-tension-nodes.md` 都把这条线压得很清楚了。

建议在分期或关键张力部分加一句。
晚年回答里，要同时看群众动员与路线斗争的内部逻辑，以及中美接近与国际均势的外部逻辑，不能只看其一。

这句会直接阻止 agent 把晚年毛写成单一的纯内斗人物，或者反过来只写成现实主义外交家。

## 九、暂时不要做的修订
