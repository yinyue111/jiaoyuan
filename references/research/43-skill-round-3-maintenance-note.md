## 一、这轮先给总判断

当前 `SKILL.md` 已经把主骨架立住了。

触发边界有了。
事实题先研究再回答有了。
主要矛盾 对象划分 阶段判断 动作建议 这条骨架也有了。
分期和关键张力也写进去了。

但基于 `36` 到 `40` 这一批新增材料再看，主文件还有四个口子没完全收死。

第一，路由还可以更硬。
现在已经不差了，但对 `1926—1927`、`1949—1956`、`1956—1957` 的优先读法还不够显性，agent 还是可能一股脑先读总账地图，或者靠印象硬答。

第二，边界还可以再收一刀。
尤其是群众路线、统一战线、斗争框架，虽然已经写了不能变成现实煽动模板，但还没把高代价历史节点不得只讲策略不讲后果这条写得足够扎手。

第三，廉价主席腔的禁令还不够狠。
目前已经禁了部分高压词和企业黑话，但从 `22-style-and-method.md`、`36` 这类维护材料看，真正最容易跑偏的不是不会像毛，而是太像廉价生成器，靠敌人 路线 纸老虎 炮打司令部 这些词硬装气势。

第四，`1926—1927` 与 `1949—1957` 的读法提醒还没完全压成 agent 级规则。
现在主文件有分期和若干路由，但新材料已经足够证明，这两段都不能按旧习惯粗读。
前者不能只当农运高潮。
后者不能拆成建国重建一块、人民内部矛盾一块然后各说各的。

一句话说完。
这一轮最该做的，不是继续往 `SKILL.md` 加知识点。
是把新增 research 里的高价值结论压成更硬的路由、禁令和提醒句。

## 二、哪些新规则必须回灌 `SKILL.md`

### 1. 把 `1926—1927` 的专门路由写硬

这一条必须回灌。

`40` 已经把这段重新钉得很清楚。
`1926—1927` 不能只按湖南农运高涨来读。
更稳的骨架是三件事同时看。
制度平台。
干部复制链。
统一战线内部领导权冲突。

所以主文件里关于研究路由的段落，应该把下面这层意思写死。

用户问 `1926—1927`、广州农讲所、湖南农民运动考察报告、统一战线前夜农民问题、谁领导革命这类题时，优先读 `references/research/40-1926-1927-peasant-movement-and-leadership-conflict-round-2.md`，再按需回看 `32-1926-1927-peasant-movement-and-leadership-conflict.md` 和 `16-party-building-1921-1927.md`。

这条会直接改变回答质量。
因为它能阻止 agent 把这段写成单纯农民苦难叙事，或者写成纯青年热血。

### 2. 把 `1949—1956` 的法政重建路由单独写硬

这一条也必须回灌。

`38` 已经补得很扎实。
建国初期这段不能只按联合政府设计、新民主主义、国家建设那种宽泛概括去答。
遇到共同纲领、土改法、镇反、1954 宪法、人民民主专政、过渡时期这些对象时，必须优先走法政文本链。

也就是至少知道这条线。
`共同纲领第七条 -> 双十指示 -> 惩治反革命条例 -> 1954宪法第十九条`

主文件里要加成路由规则。
用户问 `1949—1956` 的国家设计、共同纲领、土改、镇反、1954宪法、人民民主专政时，优先读 `references/research/38-1949-1956-state-reconstruction-legal-texts-round-2.md`，再配 `34-state-building-legal-text-pack.md` 与 `19-state-building-1945-1956.md`。

这条很值钱。
因为它能把这段从抽象国家建构，压回具体制度文本和张力链。

### 3. 把 `1956—1957` 的合读规则写成硬提醒

这一条必须回灌。

`37` 已经讲明白了。
`1956—1957` 不能把《论十大关系》和《关于正确处理人民内部矛盾的问题》拆开读。
前者偏治理平衡术。
后者偏矛盾分类与处理方法。
两者合起来，才能看出建国后治理转折的全貌。

而且必须同时保留同年急转的张力。
只写柔性治理语言，会把历史写假。
只写反右急转，又会把前面的公开理论框架抹平。

所以这条不该只留在 `references/`。
应该进主文件，作为 `1956—1957` 的默认读法提醒。

### 4. 把事实底稿要求补成 对象 时间 时期位置 争议点

这条是对现有规则的升级。

现在 `SKILL.md` 已经要求事实底稿覆盖对象、时间、阶段、争议点。
这一轮建议把 阶段 进一步压成 时期位置。
因为 `37`、`38`、`39`、`40` 都说明，很多问题不是缺事实，而是缺放置位置。

比如问群众路线。
问统一战线。
问国家重建。
问人民内部矛盾。
如果不先说这个问题落在毛哪一段，后面极容易把不同阶段揉平。

所以这条建议属于必须回灌，但只是小改。
不是重写工作流。

### 5. 把 廉价主席腔 禁令单列出来

这一条必须回灌。

`36` 已经把问题说透了。
`22-style-and-method.md` 也能支撑。
真正最容易让 `jiaoyuan` 降级的，不是结构失真，而是为了像毛而堆毛词。

所以在现有 表达DNA 的禁止项里，建议单列一条更硬的禁令。
不要靠连续高压词汇、口号句、历史戏剧词装气势。
不要把 敌人 路线斗争 纸老虎 炮打司令部 这种词当风格装饰。
不要把用户当群众大会听众。

这条写进去之后，能明显降低油腻感和生成器味。

### 6. 把高代价历史节点不得只讲策略不讲后果写得更狠

这条也应该回灌。

当前主文件已经写到不能靠修辞洗白。
方向对。
但还不够硬。

新增材料尤其是 `37`、`38`、`39` 反复说明。
`1957`、镇反、建国初高压治理、晚年对内高压与对外现实主义并存，这些都不能只用战略语言顺着说过去。

更稳的写法是。
涉及镇反、反右、大跃进、文革等高代价节点时，必须同时交代治理逻辑与后果争议。
不得只谈策略成败，不谈代价。

### 7. 把晚年 对内高压 与 对外现实主义并存 写成默认提醒

这条值得回灌，但优先级略低于前六条。

`39` 已经把这段钉得很硬。
晚年不能只写成派系宫斗。
也不能只写成中美接近的大战略现实主义。
更稳的读法是，对内继续革命和高压定性逻辑未退，对外却能接受与意识形态敌手做交易性重组。

主文件里已有相关张力句。
这一轮建议压得更短、更像默认提醒句。
这样 agent 回答 `1973—1976` 时不容易偏一边。

## 三、哪些内容仍应留在 `references/`

### 1. `37` 到 `40` 的长篇事实综述本身，应继续留在 `references/`

这些稿子很值钱。
但它们的价值主要是给回答提供事实底稿、具体路由、制度链和维护依据。
不适合直接整体搬进主文件。

`SKILL.md` 只该吸收它们提炼出来的路由句、边界句和提醒句。
不能把长综述再塞进去，不然又会发胖成半本人物总论。

### 2. 具体制度链、条文细节、来源链接，都继续留在 `references/`

像 `38` 里共同纲领 土改法 镇反条例 1954宪法的具体条文与来源入口。
像 `39` 里 FRUS、Britannica、党史网的会谈纪要和事实链。
像 `40` 里广州农讲所、农协扩张和统一战线冲突的研究串接。

这些都不该进主文件。
主文件只保留路由说明和读法提醒。

### 3. 维护史和修订计划稿，继续留在维护层

`36` 和本稿这种文件，都是给维护者看的。
不是给运行时 agent 当直接知识正文的。

所以它们应该继续留在 `references/research/` 或维护层，不要回塞 `SKILL.md`。

### 4. 表达细颗粒分析，继续留在 `22-style-and-method.md` 等维护稿

廉价主席腔为什么会形成。
哪些词容易把回答写油。
哪些表达像毛，哪些只像模板。
这种细颗粒分析很有用。
但不该全部搬进主文件。

主文件只要写几条硬禁令就够了。
更多解释继续留在 `references/`。

## 五、为什么 `1926—1927` 与 `1949—1957` 要单独压读法

### 1. `1926—1927` 不能再按老套路写成 农运高潮

`40` 已经把问题说透。
这一段真正值钱的，不只是农会人数涨了，不只是农民被看见。
而是毛第一次在全国革命政治中枢附近，同时摸到 农民组织化、干部训练、地方权力再分配、统一战线内部领导权冲突 这几件事一起爆开。

所以主文件必须提醒 agent。
写这段时要看 制度平台、干部复制链、领导权冲突。
不是只会背《湖南农民运动考察报告》里那几句名句。

### 2. `1949—1957` 不能再切成 平滑建国 再加 一个急转

`38` 和 `37` 拼起来之后，这段的读法已经很清楚。

`1949—1956` 里很多后来的高压逻辑，并不是 `1957` 才凭空冒出来。
它们在共同纲领、镇反条例、1954 宪法总纲等文本里已经被制度化。

而 `1956—1957` 的关键也不是突然从柔到硬。
更准确的说法是，治理平衡术和人民内部矛盾分类法确实被公开提出，但重划边界的制度锁并没有形成，所以同年急转张力一直悬着。

所以主文件必须提醒 agent。
这段既不能写成顺滑的国家重建史，也不能写成毫无前史的突然失控史。

## 六、一个最小修改优先级

如果维护者只准备动一轮，而且想少改几刀，我建议优先级就按这个顺序。

第一刀。
先替换 `Step 2 事实底稿与读法路由`。
这会立刻改善回答稳定性。

第二刀。
给 `使用边界` 补上高代价节点、现实煽动模板、`1957` 以后张力默认检查这三条。

第三刀。
把 廉价主席腔 禁令单列出来，压风格跑偏。

第四刀。
补一段 分期读法提醒，把 `1926—1927` 和 `1949—1957` 这两段钉死。

第五刀。
在 诚实边界 里补一句 引用依 research pack 已核入口。

这样改，收益最大。
而且不会把主文件重新改胖。

## 七、最后结论

第三轮最该干的活，不是继续往 `SKILL.md` 里加材料。

是把新增 research 压成四样东西。
更硬的路由。
更狠的边界。
更清楚的分期读法。
更低油的表达禁令。

尤其要把两段读法写死。

`1926—1927` 看制度平台、干部复制、领导权冲突。

`1949—1957` 看国家重建的法政制度链、治理平衡术、矛盾分类框架，以及同年急转的张力。

再把廉价主席腔狠狠干掉。
这套 skill 就会更像一份真能驱动 agent 的执行文件。
而不是一份材料很厚、但还容易油起来的人物 prompt。
